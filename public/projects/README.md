# Project Screenshot Images Directory

Place your project homepage images or screenshots in this folder (`public/projects/`).

Recommended image names:
- `bulls-cows.png` (or `.jpg`) - Image for Bulls & Cows
- `datatrustx.png` (or `.jpg`) - Image for DataTrustX-AI
- `burn-it-nxt.png` (or `.jpg`) - Image for Burn IT NxT
- `shopez.png` (or `.jpg`) - Image for ShopEZ

Supported formats: `.png`, `.jpg`, `.jpeg`, `.webp`, `.svg`.
If you name your files differently, update the `image` field in `src/data/portfolio.ts`!
